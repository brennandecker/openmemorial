# Security

Please report security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/brennandecker/openmemorial/security/advisories/new). Do not include credentials, personal submissions, real family information, or active authentication tokens in public issues or pull requests.

Include the affected version or commit, reproduction steps using synthetic data, and the impact. We currently maintain the `main` branch. Security reports are reviewed by the maintainer as time allows; this community project does not promise a response deadline.

For deployed instances, keep Cloudflare Access and Worker secrets outside Git, restrict reviewers by exact email address, enable bot verification, and apply the database migrations. Public deployments must configure their own privacy contact and policies. See [MODERATION.md](MODERATION.md).
